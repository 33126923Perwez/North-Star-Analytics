# NorthStar Urban Mobility Analytics

This repository contains the Google Colab notebook and supporting files for the NorthStar Urban Mobility and Logistics database and analytics coursework.

## Project Overview
The project analyses operational performance, delivery failures, customer complaints, incidents, and platform events using SQL, Python, R-related analytics, and MongoDB Atlas.

## Technologies Used
- Google Colab
- Python
- Pandas
- NumPy
- SQLite
- Matplotlib
- MongoDB Atlas
- PyMongo

## Repository Contents
- NorthStar_Analytics.ipynb: Main analysis notebook
- Screenshots: Evidence of code, outputs, charts, MongoDB operations, and optimisation


## Main Focus
The analysis investigates:
- delivery failures
- customer complaints
- route overrides
- hub performance
- MongoDB NoSQL design
- query optimisation using indexes and explain plans
